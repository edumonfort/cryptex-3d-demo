# El Cryptex — minijuego 3D

Minijuego web de un cryptex en 3D: gira los cinco discos, descubre la combinación e intenta abrirlo.
Si aciertas, el cryptex se abre y aparece un pergamino; si no, el mecanismo de seguridad rompe un vial de ácido.

- Hecho con Three.js (WebGL2) y Vite. El cryptex se modeló con un script de Blender; texturas, mapa y todos los sonidos se generan de forma procedural (sin recursos de terceros).
- Mejor en un navegador de escritorio reciente (Chrome, Edge, Safari o Firefox) con sonido activado; también funciona en móvil.
- Este repositorio contiene solo el sitio ya compilado.
